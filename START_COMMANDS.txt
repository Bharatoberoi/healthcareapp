Windows (PowerShell) - quick start

# 1) Activate virtual environment
& ".\.venv\Scripts\Activate.ps1"

# 2) Start everything (recommended)
.\scripts\start_all.ps1

# 3) Stop everything
.\scripts\stop_all.ps1

# 4) (Optional) Clean workspace (removes __pycache__ and .pyc)
.\scripts\cleanup_workspace.ps1

Manual commands (if you prefer to start components yourself)
-----------------
# Provider Lookup MCP
.\.venv\Scripts\python.exe app/mcp/provider_lookup_mcp.py

# Cost Estimator MCP
.\.venv\Scripts\python.exe app/mcp/cost_estimator_mcp.py

# Main API (FastAPI)
.\.venv\Scripts\python.exe run_app.py

# Serve frontend (static file)
.\.venv\Scripts\python.exe -m http.server 8080 --directory .

# Frontend URL: http://localhost:8080/frontend.html
# API docs:     http://localhost:8000/docs
