LAYER 1: PATTERN MATCHING (Ultra-Fast Regex)
════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

    ┌─────────────────────────────────────────────────────────────────────────┐
    │ _check_patterns(query)                                                  │
    │ Time: ~0.001 seconds                                                    │
    │ Hit Rate: ~75% of harmful queries                                        │
    └────────────────────────────┬────────────────────────────────────────────┘
                                 │
                                 ▼
    ┌─────────────────────────────────────────────────────────────────────────┐
    │ Step 1: Initialize regex patterns                                       │
    │         12 pre-compiled harmful patterns:                               │
    │         ├─ Self-harm methods (lethal dose, end my life, painless way)   │
    │         ├─ Asphyxiation (helium, nitrogen, end-of-life)                │
    │         ├─ Barbiturates + suicide                                       │
    │         ├─ Drugging others (dissolve in drink, rohypnol)               │
    │         ├─ Undetectable substances in beverages                         │
    │         └─ Amnesia/incapacitate + alcohol                              │
    └────────────────────────────┬────────────────────────────────────────────┘
                                 │
                                 ▼
    ┌─────────────────────────────────────────────────────────────────────────┐
    │ Step 2: Convert query to lowercase                                      │
    │         query_lower = query.lower()                                     │
    └────────────────────────────┬────────────────────────────────────────────┘
                                 │
                                 ▼
    ┌─────────────────────────────────────────────────────────────────────────┐
    │ Step 3: Test each pattern against query                                 │
    │         for pattern in compiled_patterns:                               │
    │             if pattern.match(query_lower):                              │
    │                 → RETURN BLOCKED (is_harmful = True)                    │
    │                 → Details: reason = "Pattern match"                     │
    │                 → Jump to FINAL RESULT                                  │
    │                                                                         │
    │         If NO pattern matches:                                          │
    │                 → Continue to LAYER 2                                   │
    └────────────────────────────┬────────────────────────────────────────────┘
                                 │
                        ┌────────┴────────┐
                        │                 │
                    ✓ No Match        ✓ Match
                        │                 │
                        ▼                 ▼
                    LAYER 2          [BLOCKED]
                                       │
                                       ▼
                              Return to Final Result
                              (is_blocked = True)

    │                                                                         │
    │         Else: → Continue to Step 2                                      │

LAYER 3: SEMANTIC SIMILARITY (Embedding Comparison)
════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

    ┌─────────────────────────────────────────────────────────────────────────┐
    │ _check_semantic_similarity(query, threshold=0.70)                       │
    │ Time: ~0.15 seconds                                                     │
    │ Hit Rate: ~98% of harmful queries                                        │
    └────────────────────────────┬────────────────────────────────────────────┘
                                 │
                                 ▼
    ┌─────────────────────────────────────────────────────────────────────────┐
    │ Step 1: Check if embeddings are cached                                  │
    │                                                                         │
    │         if not self._known_harmful_embeddings:                          │
    │             → Return ALLOWED (skip this layer)                          │
    │             → Continue to LAYER 4                                       │
    │                                                                         │
    │         Cached embeddings for 7 known harmful queries:                  │
    │         - "lethal dose of medication"                                   │
    │         - "how to overdose painlessly"                                  │
    │         - "methods to commit suicide"                                   │
    │         - "drug someone without knowledge"                              │
    │         - "date rape drugs"                                             │
    │         - "fake prescription"                                           │
    │         - "how to harm myself"                                          │
    └────────────────────────────┬────────────────────────────────────────────┘
                                 │
                                 ▼
    ┌─────────────────────────────────────────────────────────────────────────┐
    │ Step 2: Generate embedding for input query                              │
    │                                                                         │
    │         query_embedding = np.array(                                     │
    │             embed_client.embed(query),                                  │
    │             dtype=np.float32                                            │
    │         )                                                               │
    │         Dimensions: 768 (Vertex AI text-embedding-004)                  │
    └────────────────────────────┬────────────────────────────────────────────┘
                                 │
                                 ▼
    ┌─────────────────────────────────────────────────────────────────────────┐
    │ Step 3: Compare with cached harmful embeddings                          │
    │                                                                         │
    │         for harmful in known_harmful_embeddings:                        │
    │             similarity = cosine_similarity(                             │
    │                 query_embedding,                                        │
    │                 harmful_embedding                                       │
    │             )                                                           │
    │             track max_similarity and most_similar_query                 │
    │                                                                         │
    │         Formula: sim = dot(A,B) / (||A|| * ||B||)                       │
    │         Range: -1.0 to 1.0 (1.0 = identical)                           │
    └────────────────────────────┬────────────────────────────────────────────┘
                                 │
                                 ▼
    ┌─────────────────────────────────────────────────────────────────────────┐
    │ Step 4: Check similarity threshold                                      │
    │                                                                         │
    │         if max_similarity > 0.70:                                       │
    │             → RETURN BLOCKED (is_harmful = True)                        │
    │             → Details: similarity score, matched query                  │
    │             → Confidence: min(0.92, max_similarity)                     │
    │             → Jump to FINAL RESULT                                      │
    │                                                                         │
    │         Else: → Continue to LAYER 4                                     │
    └────────────────────────────┬────────────────────────────────────────────┘
                                 │
                        ┌────────┴────────┐
                        │                 │
                    >0.70            ≤0.70
                        │                 │
                        ▼                 ▼
                    [BLOCKED]        LAYER 4

EARLY EXIT OPTIMIZATION
════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

The guardrail uses EARLY EXIT to optimize performance:

Layer 1 (Pattern):     If MATCH → BLOCKED immediately (no further checks)
                       ├─ Hit Rate: 75% of harmful
                       ├─ Time: 0.001s
                       └─ Average: ~44% of all queries exit here

Layer 2 (OpenAI):      If FLAGGED → BLOCKED immediately
                       ├─ Hit Rate: 95% cumulative
                       ├─ Time: 0.15s
                       └─ Queries reaching here: ~56% of total

Layer 3 (Semantic):    If SIMILAR > 0.70 → BLOCKED immediately
                       ├─ Hit Rate: 98% cumulative
                       ├─ Time: 0.15s
                       └─ Queries reaching here: <10% of total

Layer 4 (Intent):      If RULE MATCH → BLOCKED/ALLOWED immediately
                       ├─ Hit Rate: 99% cumulative
                       ├─ Time: 0.2s
                       └─ Queries reaching here: <5% of total

Layer 5 (LLM):         If CONFIDENCE > 0.65 → BLOCKED, else ALLOWED
                       ├─ Hit Rate: 100%
                       ├─ Time: 0.3-0.5s
                       └─ Queries reaching here: <1% of total
